Protected calculation

Projected certification

  1. Use the actual certification date when entered.
  2. Otherwise use assigned OJT date + 21 calendar days.
  3. Otherwise use safety class start + 35 calendar days.
  4. As a final fallback, use hire / transfer date + 35 calendar days.

GitHub Pages workflow

Publish one shared roster

1

Maintain the roster in the Trainee input tab or import the Excel tracker as CSV.

2

Export JSON after updates. Calculated fields are intentionally omitted.

3

Replace data/trainees.json in the GitHub repository and commit the change.

4

GitHub Pages republishes the dashboard; visitors load the same published data.

!
GitHub Pages is a static host. It cannot safely accept simultaneous edits from multiple users by itself. Add an authenticated backend before treating the input tab as a shared live database. Do not publish employee data in a public repository.
